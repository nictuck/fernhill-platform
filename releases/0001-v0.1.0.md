# Release 0001 v0.1.0 — Flow dashboard

The first production release of the Flow dashboard: the board that shows
where every intent is in the six-stage loop, what is waiting on whom, and
what is stuck. It is live at https://fernhill-flow.netlify.app on real data
from `nictuck/fernhill-platform` and `nictuck/fernhill-flow`.

**This record was written after the production deployment, not before.**
EX-002 delegates gate 5, so the `release` workflow fast-forwarded
`production` on the merge of 2026-11-02 19:07Z, before any record existed.
`/release` assumes the record precedes a human approval; under a `release`
grant the record is the only human-readable evidence, so it should be
written at merge time. That is follow-up F7 below. `status: authorized` is
the validator's word for "gate 5 passed"; the skill's `proposed` was never
true for this record. It lives here, in `fernhill-platform/releases/`,
because `docs/flow.md` ("Where things live") and the spec's collector table
put release records in the platform repo, where `scripts/validate-artifacts`
checks them; the product repo holds none. Everything in this file was
checked against GitHub, Netlify and the staging site on 2026-11-02 between
19:40Z and 20:20Z.
